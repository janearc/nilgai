# searches

A search is one question nilgai asks of the sky. Each has a folder of
its own: what it looks for and why, the stages it runs, the numbers it
runs by, and where it stands.

A search folder carries its own tooling, and a .game whose targets run
it from that folder. What any search could use belongs in nilgai, or
in celestial and celestial-data, not in the search.

- [firang](firang/README.md): stars thrown out of the galactic centre,
  read for the blanets they may have eaten there.
